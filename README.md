# AI Attendance System

An intelligent attendance system using Python & OpenCV that automatically marks attendance by detecting faces through webcam.

## Features
- Real-time Face Detection using Haarcascade
- Automatically saves Name, Time, and Date to Excel (CSV)
- Personalized - asks for student name
- Simple & Fast - no complex setup needed

## Tech Stack
- Python 3.13
- OpenCV (cv2)
- NumPy

## How to Run
```bash
pip install opencv-python numpy
py attendence.py
